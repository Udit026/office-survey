# Office Survey (React + Vite)

## Run karne ke steps
```
npm install
npm run dev
```
Browser me http://localhost:5173 khulega.

## Build
```
npm run build
```

## Questions edit karna
`src/data/questions.js` me saare rating questions, radio options aur dropdown options hain.
Submit par form data `console.log` hota hai (`src/App.jsx` -> `handleSubmit`), wahan apni API laga sakte ho.
